# 任务四：OLED 以 10 Hz 刷新

## 实现

`Core/Src/main.c` 使用 `HAL_GetTick()` 在主循环中每 100 ms 启动一帧，绘制与 I2C 发送耗时包含在这个周期中。第二行显示递增帧数，其余行保留英文、符号和“刘何瑾瑜”。新增代码位于 CubeMX 的 USER CODE 区域。

启动时先等待 20 ms 并初始化 OLED，再立即绘制第一帧。后续帧使用无符号时间差判断，兼容毫秒计数器回绕。若其他任务造成超时，则从当前时刻重新计时，避免连续补帧。

这里的 10 Hz 指应用向 OLED 刷新显示内容的频率；屏幕芯片内部扫描配置沿用原驱动。

## 在 IDE 中检查

在调试器的 Expressions 或 Live Expressions 中添加 `oledFrameCount`、`oledFrameStartMs`、`oledFramePeriodMs`、`oledRenderTimeMs`。程序持续运行时，帧数约每秒增加 10，周期保持 100 ms。单步和暂停会打断这个节奏，测量时不要停在断点处。

实体屏幕应看到 `OLED 10Hz` 和不断变化的 `Frame:..........`。提交作业时可拍摄短视频记录帧数变化，并附上 main.c 中 100 ms 调度代码截图。
